# Super-Store-sales-Dashboard

🎯 Objective
The main objective of this project is to build an interactive Super Store Sales Dashboard using Power BI to visualize and analyze sales data. The dashboard provides a comprehensive overview of sales performance across different regions and products. Additionally, sales forecasting is integrated to predict future sales trends, enabling decision-makers to plan effectively for the future.

📝 About This Project
This project focuses on two main aspects: creating a Super Store Sales Dashboard and integrating sales forecasting to predict future trends.

Dashboard Creation:
The primary feature of the project is the Super Store Sales Dashboard built in Power BI. The dashboard presents key metrics, including:

Total Sales

Sales by Region

Product Performance

Monthly Sales Trends

Comparison between actual and forecasted sales

Sales Forecasting:
The dashboard also includes a sales forecasting model that uses historical sales data to predict future sales trends. The forecast provides insights into expected sales growth, allowing managers to plan for demand spikes and identify potential areas of improvement.

Data Preparation:
Sales data was imported and cleaned using Power Query in Power BI. The data was transformed into a format suitable for analysis, allowing for better insights and accurate forecasting.

Visualizations and Insights:
Various interactive charts and graphs were created to display the sales data and forecasted trends. These visualizations provide a detailed and easy-to-understand view of sales performance.

💡 Key Insights
The dashboard provides several valuable insights from both the historical sales data and the forecasted trends:

Top Products: Product X and Product Y consistently perform well, contributing to the bulk of the sales.

Regional Sales Trends: Region 1 shows the highest sales, but Region 3 shows strong growth potential with the right strategies.

Sales Seasonality: Sales tend to peak during Q4, with noticeable increases around the holiday season.

Forecasted Sales Growth: The forecast indicates a 10-12% growth in overall sales over the next six months, with particularly high growth in product categories A and B.

🔧 Tools & Skills Used
Power BI: Used for building the interactive dashboard, visualizing the data, and performing sales forecasting.

Excel/CSV: Utilized for storing and preparing the raw sales data before importing it into Power BI.

DAX: Applied to create custom calculations and measures, enhancing the dashboard's functionality.

Power Query: Used to clean and transform raw data into a usable format.

Time Series Forecasting: Incorporated to predict future sales based on historical trends.
